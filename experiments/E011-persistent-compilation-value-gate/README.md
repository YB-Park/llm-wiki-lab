# E011 — Persistent Compilation Value Gate

Status: design / pre-scoring

This experiment asks whether persistent compiled synthesis earns lifecycle value over strong raw-evidence baselines before the project invests in detailed Wiki representation or further automation.

Stage 1A conditions: R0 raw+lexical, R1 strong raw relevant-context ceiling, C0 minimal compiled synthesis, C1 compiled synthesis+raw lexical evidence.

A negative result is a successful gate outcome.
