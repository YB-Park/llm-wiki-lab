# Advisory Reviews

This directory stores **non-binding review snapshots** that may challenge, critique, or propose hypotheses about the LLM Wiki architecture.

An advisory review is **not**:

- an ADR;
- accepted project policy;
- an implementation plan;
- evidence that overrides a preregistered experiment;
- a new critical-path item by virtue of existing here.

Each review should identify the exact repository snapshot it reviewed so later readers can distinguish the historical subject of the review from subsequent project changes.

Project decisions still follow the repository's normal discipline: question → hypothesis/evidence → experiment where appropriate → ADR → implementation/observation/revision.

Reviews may be contradicted, partially adopted, superseded, or closed as `not planned`. Keeping the original review is useful because it preserves what concerns and alternatives were considered at that point in the project.
