# LLM Wiki is installed

This checklist is shown **inside VS Code's own Getting Started page**. Installing the extension is already complete; what is still separate is whether **this workspace** is allowed to use project memory.

LLM Wiki gives your VS Code Agent durable project memory **without treating everything the model says as truth**.

- Saved source material stays as verifiable project evidence.
- Decisions and beliefs become durable only when you explicitly confirm them.
- AI-generated summaries are optional and rebuildable.

After setup, the **LLM Wiki** sidebar gives you a small status and follow-through surface. Ordinary work still happens in normal Agent chat; you do not need to operate a separate Wiki application.

Nothing is enabled for a workspace just because the extension is installed.
